## Decisions

- **Paused and reconnecting time count toward the two hours.** Decided here, 20 October 2026, and recorded in `docs/live-voice.md` § The two-hour limit. The limit protects disk and processing, and a recording keeps one timeline: when audio returns after a pause, `MeetingAudio`'s writer fills the gap on both tracks with silence, so a paused hour costs the same disk and the same recognition passes as a recorded one. The writer's own ceiling, `MeetingSegmentPlan` and recovery's validation all bound that same timeline, and the page's clock already counts it. Excluding paused time would need the writer to stop filling pauses and the plan and recovery to accept a longer timeline: a saved-recording change in files other streams own. The warning and "pauses included" make the rule visible instead. Revisit if people pause long meetings and lose their end to the limit.
- **Start task never re-sends work that may have reached the provider** (the lead's decision on the independent review, 20 October, replacing this branch's first answer, which retried all three endings from the review). A failed task, which the runner reported, may run again from a new review. A stopped or interrupted task may have completed, so its explicit retry stays in History, behind its receipt; the review says so beside Start task and offers Show in History…, which ends the loop without a second submission. The review learns the saved task's status before the press from the same fingerprint `prepare` uses, looked up 150 ms after the review last changed so typing does not hash every keystroke. `docs/workbench.md` says this.
- **Prepare follow-up… on Home reopens only the door's own task.** The tile cannot pass a ready task's frozen request and skill into the review without changing Home's door, so it keeps Prepare follow-up… only when the task's frozen inputs are exactly the door's defaults; anything else opens in History, where that task's own Start task… is. If the transcript's words changed since, the door prepares a new task with the current words, which is the review's normal rule.
- **Copy instructions does not gain a way to paste a result back.** The tile's way forward is Start task on the same task. Bringing an assistant's reply back would be a new History action and a review step, an Option needing its own decision. Revisit if people who cannot connect a runner keep copying follow-ups and want the recap on Home.
- **The pill's compact rest has no limit badge for a meeting.** The chooser row carries the warning, but the rest's stops-soon badge and its VoiceOver description live in `ToolbarCore`, whose description names Dictate's 5-minute limit. Left for a toolbar change.

## Needs a real call to accept

On a signed Preview, by the integration owner or Ethan:

- A real call in Zoom or FaceTime whose app stops using audio: the panel's and Home's row show the countdown with Keep recording, Keep recording holds the recording, and an unheld countdown saves the meeting with "Workbench finished this recording itself. The call app stopped using audio." in History.
- A meeting started from the panel or the offer while macOS asks for permission: the panel and Home read "Meetings · starting" with Cancel start, and Cancel start ends the start.
- The last five minutes of a long recording (or a build with a shortened limit): the caption, the panel, Home and the toolbar chooser show the warning; pausing shows "pauses included".
- Copy instructions from a meeting's Prepare follow-up…, then Prepare follow-up… on Home → Start task with a connected runner: the same task runs and its recap replaces the excerpt.
- A follow-up that failed, retried from the meeting's Prepare follow-up…: History shows the new attempt with the earlier one under Previous attempts. One that was stopped or interrupted: the review says so, Start task is disabled, and Show in History… reveals its card with Retry….
- A self-finished call whose app sent no sound: Home's tile shows the no-sound note, and History keeps both notes.
- A two-hour meeting's Prepare follow-up…: the review names Copy instructions, and the copied request pastes whole into an assistant.
- Detect Meetings & Calls with metadata failing (hard to provoke on a real Mac): the page shows the failure once, × keeps it away, and it never covers a microphone problem.
